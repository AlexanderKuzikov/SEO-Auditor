# CONTEXT — SEO Auditor

> Живое состояние проекта. Обновлять в конце сессии.

## Что это

On-page аудит сайта под выдачу Яндекса: собственный краулер на стандартной библиотеке
Python, ~40 проверок, снимок в JSON и diff между прогонами. Zero dependencies.

Взят как замена обёртке `AgriciDaniel/on-page-seo` (Firecrawl + DataForSEO, платные
API, Google-only метрики). Оттуда взята идея таксономии чек-листа; код, краулер,
diff и ориентация на Яндекс — свои.

## Проверенные находки на zavodsvay.ru

Прогон 40 URL из sitemap, 2026-09-30:

- **39/40 страниц: сломан JSON-LD** — в `legalName` организации незаэкранированные
  двойные кавычки, `json.loads` падает. Разметка не работает вообще. Находка
  подтверждена вручную по сырью.
- 1 URL отдаёт 4xx/5xx, 1 не отдаётся вовсе (сетевая ошибка).
- 17 страниц тонкие (< 300 слов).
- 2 страницы-сироты без входящих внутренних ссылок, 1 группа дублей H1.

## Решения, которые важно помнить

- Отдельный репозиторий, а не модуль `SEO-Zavodsvay`: инструмент нужен для сети
  доменов, лежать в проекте одного клиента не может. Подробно в `DECISIONS.md`.
- Повторный прогон в тот же день архивируется, а не затирает снимок — иначе diff
  не имеет предыдущей точки и история теряется.
- Снимки разложены по хостам: один файл на домен в сети из пяти перетирал бы данные.
- `alt=""` у счётчика аналитики и ссылка-иконка с картинкой не считаются дефектами —
  иначе на каждом сайте будет систематический ложный шум.

## Open-проблемы

- `Crawl-delay` из robots.txt не читается, пауза фиксированная. Для чужих крупных
  сайтов прогон может быть навязчивым. Порог: ~1000 URL на домен.
- Контент отдаётся `http`-ссылками в части снимков — отдельная проверка
  «адреса в sitemap указаны в https» ещё не сделана, ловится через `REDIRECT_SCHEME`.
- Порог `THIN_WORDS = 300` не калиброван на конкретные тематики. Для локального
  коммерческого сайта 250 слов может быть нормой.
- Нет проверки «страницы из sitemap, которых нет на сайте» — сейчас ловится
  косвенно через битые URL.
- Markdown-отчёт для заказчика не генерируется: снимок есть, читать JSON неудобно.
